# System Engineering - DevOps

This repository contains scripts and tasks completed as part of the **ALX Software Engineering Programme**, specifically focusing on the **System Engineering and DevOps** track.

Each directory contains tasks that demonstrate shell scripting, process management, loops, conditions, file permissions, and more.

## 🗂 Project Structure

| Folder | Description |
|--------|-------------|
| `0x01-shell_permissions` | Tasks on Linux file permissions and ownership |
| `0x02-shell_redirections` | Tasks on input/output redirection and filtering |
| `0x03-shell_variables_expansions` | Tasks on shell variables, expansions, and command substitution |
| `0x04-loops_conditions_and_parsing` | Tasks on loops, conditional statements, and input parsing |
| `0x05-processes_and_signals` | Tasks on managing Linux processes and sending signals |

## 🛠 Technologies Used

- Bash 5.x
- Ubuntu 20.04 LTS
- Git & GitHub
- ShellCheck for static code analysis

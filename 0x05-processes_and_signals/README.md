# 0x05. Processes and Signals

This directory contains Bash scripts that demonstrate an understanding of Linux processes, process IDs (PIDs), and signal handling. Each script addresses a specific task related to managing and interacting with processes and signals in a Unix-based system.

## Topics Covered

- Retrieving and working with process IDs (PIDs)
- Listing active processes
- Using `pgrep`, `kill`, and other signal-related commands
- Sending and handling signals
- Managing background jobs

## Prerequisites

- Bash scripting knowledge
- Familiarity with Linux command line tools
- Understanding of Unix process management
